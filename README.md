# TaskAlert

Aplicación web de gestión de tareas con sistema de alarmas, prioridades y notificaciones visuales. Desarrollada con tecnologías web estándar sin dependencias externas.

## Funcionalidades

- Agregar tareas con nombre, fecha, hora y prioridad
- Editar tareas existentes
- Eliminar tareas con confirmación
- Marcar tareas como completadas
- Filtrar por prioridad (Alta, Media, Baja) y estado (Pendientes, Completadas)
- Alarma visual y sonora cuando llega la hora de una tarea
- Notificación con opción de marcar la tarea como completada directamente
- Contador de tareas totales y completadas
- Persistencia de datos con localStorage

## Conceptos aplicados

- Manipulación del DOM con JavaScript puro
- Persistencia de datos con localStorage y JSON
- Manejo de fechas y horas con el objeto Date
- Generación de audio con AudioContext API
- Animaciones con transiciones y transforms de CSS
- Diseño responsive con CSS Grid y Flexbox
- Filtrado de colecciones con el método filter()
- Separación de responsabilidades en funciones

## Uso

1. Al abrir la aplicación los datos guardados se cargan automáticamente
2. Completa el formulario con el nombre, fecha, hora y prioridad de la tarea
3. Haz click en **Agregar tarea** o presiona **Enter**
4. La aplicación enviará una notificación cuando llegue la hora programada
5. Usa los filtros para organizar la vista según tus necesidades
